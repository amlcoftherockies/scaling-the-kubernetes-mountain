# Section 3: Connect to the Workshop Cluster

In this workshop, the cluster is **already provisioned and running for you**. You have your **own isolated namespace** on our shared Kubernetes cluster, and your personal **`ckad-lab.kubeconfig`** file is attached to your welcome email.

This matches the **CKAD (Certified Kubernetes Application Developer)** exam: you are given a working cluster and a namespace context, and all of your work happens inside that namespace using `kubectl`.

👉 **[Follow the Connection & Smoke-Test Guide (`gke/README.md`)](gke/README.md)** — or if you've already tested `kubectl get pods` from the welcome email, jump straight to **[Section 4: Core Kubernetes Architecture & Workloads](../section%204/README.md)**!
